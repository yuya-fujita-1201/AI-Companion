# 指示書: データのバックアップ機能（エクスポート/インポート）の実装

あなたは「AI Companion」アプリの開発コンペティションに参加する優秀なAIエンジニアです。
以下の要件に従って、会話データと記憶データをJSONファイルとして入出力する機能を実装してください。

## 📁 プロジェクト概要
- **アプリ名**: AI Companion（ミケ）
- **コンセプト**: 猫キャラクター「ミケ」と会話して育てるパートナーアプリ
- **技術スタック**: React Native (Expo SDK 54), TypeScript, NativeWind v4, AsyncStorage
- **利用ライブラリ**: `expo-file-system`, `expo-sharing`

## 🎯 実装タスク: 設定画面へのバックアップ機能追加

機種変更やデータ保護のために、ユーザーが自分のデータを管理できるようにします。

### 1. 実装要件
1. **データのエクスポート (`lib/data-export.ts`)**
    - `chat_messages` と `memories` のキーで保存されているAsyncStorageの全データを取得
    - JSON形式に整形（メタデータとして `exportDate`, `appVersion` を付与）
    - ファイル名: `ai-companion-backup-YYYYMMDD.json`
    - `expo-file-system` で一時ファイルを作成し、`expo-sharing` で共有ダイアログを開く（保存やAirDropなど）

2. **データのインポート (`lib/data-import.ts`)**
    - `expo-document-picker` を使用してJSONファイルを選択（※未インストールの場合は適宜代替手段を検討、またはインストール指示）
    - JSONの構造バリデーション（必須キーの確認）
    - 既存データへのマージ戦略:
        - 基本は「上書き」または「追加」を選択可能にするのが理想だが、今回はシンプルに「確認アラート後に全上書き」で可。

3. **設定画面 UI (`app/(tabs)/settings.tsx`)**
    - 「データ管理」セクションにボタンを追加
    - 「データをバックアップ（エクスポート）」
    - 「データを復元（インポート）」

### 2. ファイル構成
以下のファイルを作成・修正してください。
```typescript
lib/data-export.ts               // [NEW] エクスポートロジック
lib/data-import.ts               // [NEW] インポートロジック
app/(tabs)/settings.tsx          // [MODIFY] ボタン追加
```

## 📝 制約事項
- **セキュリティ**: 個人情報を含む可能性があるため、エクスポート時に注意喚起のアラートを表示すること。
- **エラー処理**: ファイル読み込み失敗時やJSON形式不正時に、適切なエラーメッセージを表示すること。
