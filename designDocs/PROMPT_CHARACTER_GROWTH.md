# 指示書: キャラクター成長システムの実装

あなたは「AI Companion」アプリの開発コンペティションに参加する優秀なAIエンジニアです。
以下の要件に従って、ユーザーとの会話量に応じてAIキャラクターが成長するシステムを実装してください。

## 📁 プロジェクト概要
- **アプリ名**: AI Companion（ミケ）
- **コンセプト**: 猫キャラクター「ミケ」と会話して育てるパートナーアプリ
- **技術スタック**: React Native (Expo SDK 54), TypeScript, NativeWind v4, tRPC, AsyncStorage

## 🎯 実装タスク: キャラクター成長メカニズムの構築

会話回数が増えるにつれてキャラクターの「レベル」が上がり、応答の質やバリエーションが変化する仕組みを作ります。

### 1. 実装要件
1. **レベルシステムの定義 (`lib/character-level.ts`)**
    - レベル1: 0-50回 (基本)
    - レベル2: 51-150回 (語尾バリエーション増加)
    - レベル3: 151-300回 (感情表現豊か)
    - レベル4: 301回以上 (完全解放)
    - 関数: 会話数からレベルを算出するロジック

2. **レベル情報の保存と伝達**
    - `AsyncStorage` にレベル情報をキャッシュ
    - **重要**: `server/routers.ts` (チャットAPI) のシステムプロンプトに、現在のレベル情報を動的に注入する仕組みを実装。
    - プロンプト内での指示: 「現在のレベルはXです。レベルXに応じた振る舞いをしてください（例: ...）」

3. **レベルアップ演出 (`components/level-up-modal.tsx`)**
    - 会話終了時にレベルアップを検知したら、モーダルを表示
    - お祝いメッセージと、解放された機能の説明を表示

### 2. ファイル構成
以下のファイルを作成・修正してください。
```typescript
lib/character-level.ts           // [NEW] レベル計算ロジック
components/level-up-modal.tsx    // [NEW] お祝いモーダル
app/(tabs)/index.tsx             // [MODIFY] 会話後の判定ロジック追加
server/routers.ts                // [MODIFY] システムプロンプトへのレベル反映
```

## 📝 制約事項
- **サーバーサイド**: `server/routers.ts` の `chat.sendMessage` 手続きを修正する際は、既存のロジックを壊さないように注意してください。
- **UX**: レベルアップのモーダルはユーザーの邪魔にならないタイミング（AIの返信完了後など）で表示すること。
