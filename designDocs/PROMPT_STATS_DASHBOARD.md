# 指示書: 会話統計ダッシュボードの実装

あなたは「AI Companion」アプリの開発コンペティションに参加する優秀なAIエンジニアです。
以下の要件に従って、ユーザーとの会話データを可視化する「統計ダッシュボード」機能を実装してください。

## 📁 プロジェクト概要
- **アプリ名**: AI Companion（ミケ）
- **コンセプト**: 猫キャラクター「ミケ」と会話して育てるパートナーアプリ
- **技術スタック**: React Native (Expo SDK 54), TypeScript, NativeWind v4, tRPC, AsyncStorage
- **デザイン**: プレミアムで温かみのあるUI（オレンジ・茶色・クリーム色基調）

## 🎯 実装タスク: 会話統計ダッシュボードへの「統計」タブ追加

ユーザーのエンゲージメントを高めるため、会話データを可視化する新しい画面を作成します。

### 1. 実装要件
1. **新規タブの追加 (`app/(tabs)/stats.tsx`)**
    - タブバーに「統計」を追加（アイコン: `chart.bar.fill` または `chart.pie.fill`）
    - ヘッダータイトル: 「ミケとの記録 📊」

2. **表示する統計データ (`components/stat-card.tsx`)**
    - **総会話数**: 累積メッセージ数
    - **一緒にいる日数**: 初回起動日からの経過日数
    - **なかよし度**: 0-100%（会話数に基づく）
    - **今週の会話数**: 過去7日間の棒グラフ
    - **よく話すトピック**: 記憶データから抽出したキーワード（ダミー実装で可、または`MemoryType`ごとのカウント）

3. **グラフの実装**
    - `react-native-chart-kit` を使用して、週間会話数を棒グラフで表示
    - なかよし度をプログレスリングまたは円グラフで表示

4. **マイルストーンバッジ (`components/milestone-badge.tsx`)**
    - 条件達成で色が付くバッジ一覧（例: 「初めまして」「100回会話」「7日連続」）

### 2. データソース
- `AsyncStorage` から `chat_messages` (JSON配列) を取得して計算してください。
- `timestamp` プロパティを使用して日次集計を行います。

### 3. ファイル構成
以下のファイルを作成・修正してください。
```typescript
app/(tabs)/stats.tsx             // [NEW] メイン画面
app/(tabs)/_layout.tsx           // [MODIFY] タブ追加
components/stat-card.tsx         // [NEW] 統計カード
components/milestone-badge.tsx   // [NEW] バッジコンポーネント
lib/stats-calculator.ts          // [NEW] 集計ロジック
```

## 📝 制約事項
- **UIデザイン**: `ScreenContainer` コンポーネントを使用し、既存の `memories.tsx` や `settings.tsx` と統一感を持たせること。
- **スタイリング**: Tailwind CSSクラス (`className`) を使用すること。
- **エラー処理**: データが空の場合（初回起動直後）でもクラッシュせず、「まだデータがないにゃ」等のメッセージを表示すること。
