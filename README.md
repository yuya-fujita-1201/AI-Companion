# AI Companion - あなたのAIパートナー

AI Companionは、スマートフォンから音声やテキストでAIと対話し、会話を通じてAIがあなたのことを学び、記憶していくモバイルアプリです。

## 主な機能

### 💬 自然な会話
- テキストチャットでAIと対話
- 音声入力機能（長押しで録音、離すと送信）
- リアルタイムでAIが応答を生成
- 会話履歴の自動保存

### 🧠 記憶システム
- 会話から自動的に重要な情報を抽出
- 4種類の記憶タイプ
  - **事実**: ユーザーに関する基本情報
  - **好み**: ユーザーの嗜好や興味
  - **イベント**: 重要な出来事や予定
  - **会話要約**: 会話全体の要約
- 記憶の重要度スコアリング（1-10）
- 記憶の種類別フィルター表示

### 📱 使いやすいUI
- iOS Human Interface Guidelinesに準拠したデザイン
- ダークモード対応
- 直感的なタブナビゲーション
- スムーズなアニメーション

## 技術スタック

- **フレームワーク**: React Native (Expo SDK 54)
- **言語**: TypeScript
- **スタイリング**: NativeWind (Tailwind CSS)
- **状態管理**: React Hooks + AsyncStorage
- **API通信**: tRPC
- **音声認識**: Expo Audio + サーバー側Whisper API
- **AI**: サーバー内蔵のLLM (Gemini 2.5 Flash)

## セットアップ

### 必要な環境
- Node.js 22.x
- pnpm 9.x
- Expo Go アプリ（実機テスト用）

### インストール

```bash
# 依存関係のインストール
pnpm install

# 開発サーバーの起動
pnpm dev
```

### 実機でのテスト

1. スマートフォンにExpo Goアプリをインストール
2. 開発サーバー起動後に表示されるQRコードをスキャン
3. アプリが自動的に起動します

## 使い方

### チャット画面
1. テキスト入力フィールドにメッセージを入力して送信
2. または、音声入力ボタンを長押しして話す
3. AIが応答を生成して表示

### 記憶画面
1. タブバーから「記憶」をタップ
2. AIが覚えている情報を一覧表示
3. 種類別にフィルターして表示可能
4. 不要な記憶はスワイプで削除

### 設定画面
1. タブバーから「設定」をタップ
2. 会話履歴の削除
3. すべてのデータの削除

## アーキテクチャ

### クライアント側
- **app/(tabs)/**: タブナビゲーション画面
  - `index.tsx`: チャット画面
  - `memories.tsx`: 記憶一覧画面
  - `settings.tsx`: 設定画面
- **components/**: 再利用可能なコンポーネント
- **lib/**: ユーティリティ関数
- **types/**: TypeScript型定義

### サーバー側
- **server/routers/**: tRPCルーター
  - `chat`: チャット機能
  - `voice`: 音声認識
  - `memory`: 記憶管理
- **server/_core/**: コア機能
  - `llm.ts`: LLM API統合
  - `voiceTranscription.ts`: 音声文字起こし

## データの保存

- **会話履歴**: AsyncStorageにローカル保存
- **記憶データ**: AsyncStorageにローカル保存
- すべてのデータはデバイス内に保存され、外部に送信されません
